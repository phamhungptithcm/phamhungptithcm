## How I Work

- Model business workflows clearly, especially when money movement, refunds, disputes, or customer operations are involved.
- Keep service boundaries explicit so distributed systems stay understandable as they grow.
- Treat payment actions as stateful operations that need traceability, idempotency, auditability, and safe recovery paths.
- Use observability as part of delivery: logs, metrics, traces, dashboards, alerts, and runbooks.
- Review code for correctness, readability, supportability, and production behavior.
- Mentor engineers with practical feedback, not just abstract rules.
